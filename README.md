## Featured projects

### ESP32 Master-Slave BLE

One pushbutton controls LEDs on two other ESP32 boards over Bluetooth
Low Energy. My individual build includes firmware, wiring, and recorded
hardware demonstrations.

[Explore the BLE project](https://github.com/xavieryyyyyy/esp32_master-slave-ble_comm)

### Real-Time Room Monitoring

An ESP32 project using FreeRTOS to manage sensor readings, an OLED
display, and a temperature alarm. The repository includes a Wokwi
simulation demonstration.

[Explore the room monitor](https://github.com/xavieryyyyyy/esp32-freertos-room-monitoring-system)
